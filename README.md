137 characters, one line, written for this bounty. The complaint is specific
(cheap salmon, late serving, stolen bed side) and the sting lands in the last

## How it runs

`main.py` (Python 3.13, standard library only) reads `entry.txt` next to it,
checks it against the gate (1–200 characters, a single non-blank line), and
writes it unchanged to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`):

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Deterministic: the same input bytes produce the same output bytes on every run.
